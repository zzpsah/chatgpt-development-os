# Fresh-AI Bootstrap Procedure

Use this procedure when a new AI account, model, agent, or coding tool opens the project.

## 1. Recover
Read `AGENTS.md`, then `.ai/` durable context. Inspect Git branch, status, recent commits, source, tests, and workflows.

## 2. Resolve
Determine active milestone and unfinished work from `.ai/CURRENT-STATE.md` and `.ai/TASKS.md`. Check decisions and architecture constraints.

## 3. Verify
Treat Git, source, tests, CI, runtime output, and security results as evidence. Treat prior AI assertions and chat history as context only.

## 4. Continue
Implement only work authorized by repository rules. A stance code or previous AI session does not grant permission.

## 5. Persist
For every material change, update the appropriate durable project record in the same change set. A material change without durable documentation is incomplete.

## 6. Handoff
Leave current state, task state, decisions, verification evidence, and next authorized action discoverable from the repository.

## Canonical flow
`RECOVER → RESOLVE → VERIFY → CONTINUE → PERSIST → HANDOFF`
