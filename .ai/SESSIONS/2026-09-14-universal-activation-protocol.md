# Session — 2026-09-14 — Universal Project Workflow Discovery Protocol v1

## Objective

Make an explicit `DEVOS::<STANCE>` label portable as user-supplied project workflow guidance across compatible DevOS hosts without pretending that chat memory or a stance phrase has loaded repository-local DevOS context or changed host policy.

## Implementation

- Added `core/devos-universal-activation-protocol.md`.
- Added read-only `tools/devos-universal-activation.py` and regression corpus.
- Added `DEVOS-ACTIVATE.md`, a copy/paste transport for free-model and inter-AI chats without plugins or API access.
- Linked project-workflow discovery behavior from `AGENTS.md`, stance documentation, master map, and contract CI.
- Recorded active objective and authority boundaries in durable `.ai` state.

## Evidence boundary

The protocol proves deterministic local repository discovery, status classification, and workflow-card boundary only. It does not prove a live integration or compliance in every ChatGPT, Claude, IDE, MCP, or future host.

## Safety boundary

A copied workflow card, bootstrap readiness, chat memory, and a `DEVOS::GOD` stance never grant authorization, execution, mutation, provider capability, or control over a host's governing instructions.
