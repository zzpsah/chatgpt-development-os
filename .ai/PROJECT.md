# Development OS — Project Context

## Purpose

Development OS (DevOS) is a portable, human-language-first development operating system for working across projects, AI accounts, AI coding tools, and machines.

This repository is the DevOS framework itself. It defines the contracts, workflows, adapters, verification rules, and tooling that managed projects use.

## Durable context rule

Project-local durable context is authoritative for project-specific state. Source code and Git history are authoritative for implementation and exact changes. AI account memory is supplementary only.

## Communication model

DevOS supports natural language, Hinglish, slang, humor, frustration, and engineering shorthand. Conversational style must never weaken authorization, security, evidence, or verification requirements.

Core rule: **Funny input. Serious engineering.**
