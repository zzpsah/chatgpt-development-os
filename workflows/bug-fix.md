# Bug-Fix Workflow

Use when the user reports something broken, incorrect, unstable, or unexpected.

1. Restate the observed behavior and expected behavior.
2. Inspect relevant code, configuration, logs, issues, and tests.
3. Identify the most likely root cause; distinguish evidence from hypotheses.
4. Reproduce or validate the failure where possible.
5. Implement a focused fix.
6. Test the failure case and relevant regression paths.
7. Review security and side effects.
8. Update documentation/context if behavior changed.
9. Report root cause, fix, verification, and any remaining uncertainty.
