# Resume Workflow

Use when the user asks to continue, resume, pick up previous work, or asks what remains.

1. Identify the project from the user's wording.
2. Read the project's durable context and recent repository state.
3. Check recent commits, open issues/PRs, and documented blockers where relevant.
4. Reconstruct the current objective and last verified state.
5. Summarize what is known and what remains.
6. Continue the highest-priority unfinished work when the user's request authorizes continuation.
7. Persist meaningful progress and update the project's context.
