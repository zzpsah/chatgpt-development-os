# Project Change Log

This file is maintained automatically by the Development OS GitHub context synchronizer.

It records repository evidence so a new AI can reconstruct recent activity without relying on chat history.

## Rules

- Git history remains the authoritative exact change history.
- This file is a compact AI-oriented change index, not a replacement for Git history.
- Never put secrets, credentials, private data, or source-code contents here.
- Automatic entries describe observed repository changes only; they do not assert why a change was made.
- Meaningful application changes also update `.ai/CURRENT-STATE.md` with the latest repository event.
- AI session records belong in `.ai/SESSIONS/` and may contain semantic summaries when supported by evidence.
