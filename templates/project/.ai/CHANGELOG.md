# Project Change Log

This file is maintained automatically by the Development OS GitHub context synchronizer.

It records repository changes so a new AI can quickly reconstruct recent activity without relying on chat history.

## Rules

- Git history remains the authoritative exact change history.
- This file is a compact AI-oriented change index.
- Never put secrets or sensitive data here.
- Meaningful application changes also update `.ai/CURRENT-STATE.md` automatically.
