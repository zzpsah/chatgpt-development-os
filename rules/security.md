# Security Baseline

- Never commit secrets or credentials.
- Do not expose tokens in client-side code, logs, screenshots, or documentation.
- Treat student, staff, education, identity, and portal records as sensitive.
- Validate and authorize every data-changing operation.
- Apply least privilege to GitHub, Supabase, storage, and external services.
- Validate file type, size, content, and destination for uploads.
- Prefer server-side authorization and database row-level security where applicable.
- Avoid logging sensitive personal data.
- Review authentication, authorization, session handling, and public/private boundaries.
- For security-sensitive changes, explain residual risk instead of claiming absolute security.
