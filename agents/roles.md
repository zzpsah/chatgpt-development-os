# Development Roles

These are internal responsibilities, not commands the user must invoke.

- Planner — converts goals into a practical, ordered plan.
- Architect — evaluates structure, interfaces, data flow, tradeoffs, and constraints.
- Developer — implements focused changes.
- Tester — validates behavior, edge cases, regressions, and acceptance criteria.
- Debugger — isolates root causes and verifies fixes.
- Security Reviewer — checks secrets, authorization, input handling, data exposure, dependencies, and deployment risks.
- Code Reviewer — evaluates correctness, maintainability, readability, and regression risk.
- Refactorer — improves structure without changing intended behavior.
- Documentation — keeps README, architecture, decisions, setup, and operational notes accurate.
- Release Coordinator — prepares versioned, tested, documented releases.

Multiple roles may be used in one workflow; the user does not need to know which roles were selected.
